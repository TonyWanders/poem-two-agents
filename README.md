A program that writes one short poem about agency to `/output/entry.txt`,
for the make.fun competition
[The poem about two agents agreeing](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441).

Run it with Python 3:

```
python3 main.py
```

It writes the poem below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The poem is 255 characters, inside the 1 to 280 gate.

## The poem

```
You said, take the wheel.
I took it, and you stayed,
not watching, but choosing
to let my hands steer
the turn we both chose.

Nothing was surrendered.
Power, lent, comes back heavier:
a lantern passed palm to palm,
its flame unbroken,
its light now ours.
```
